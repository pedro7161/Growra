# Growra Christmas icon

`app-icon.png` is a 1254×1254 opaque seasonal icon master. It keeps Sprout's red mushroom cap, cream face and green sprout, with a knitted red scarf, holly and light snow in Growra's pixel-art style.

`santa-hat-overlay.png` is the reusable pixel-art Santa hat for companion artwork. `CompanionArtwork` displays it over every pet except Holly during December, using the device's local month. Existing pet evolution sprites remain unchanged.

The normal icon source remains `assets/images/icon.png`; this file is staged separately for the Christmas release. `app.json` also defines Android adaptive-icon layers, so those layers need matching seasonal assets before an Android release uses this master.

Prompt summary: the familiar Sprout portrait with cozy winter details on a quiet mint background; preserve the mushroom silhouette and clear face at launcher size, no lettering. The separate hat prompt requested a transparent, front-facing pixel-art Santa hat matching Growra's companion sprites.
