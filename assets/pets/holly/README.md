# Holly

Christmas companion concept: a friendly chestnut-and-cream winter fawn with holly antlers, a red scarf and a gold bell.

- `base.png`: young fawn form
- `evo1.png`: woodland guardian with fuller antlers and a leafy mantle
- `evo2.png`: radiant winter stag with broad evergreen antlers

All three are 1254×1254 RGBA sprites with transparent backgrounds, generated in Growra's detailed pixel-art style. Prompt set: keep the same face, colors and festive accessories across the three growth stages, with each stage growing more magical and majestic.

These are staged art assets. The companion is not registered in the app's pet template or companion-unlock systems yet; those need an event availability rule before the art can appear in-game.
